Entry for the make.fun **Fortune Cookie for the Liquidated Trader** bounty: exactly one fortune-cookie line for a crypto trader who has just been liquidated. The fortune reframes the loss as tuition paid to the market, and promises the diploma in patience with the next green candle — rueful, warm, and oracular, with the punch landing on the last words.

## Run

```bash
python3 main.py
```

This writes the one-line fortune to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output`).
